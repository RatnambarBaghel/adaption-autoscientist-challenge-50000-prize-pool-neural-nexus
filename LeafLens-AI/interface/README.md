# Interface

LeafLens AI does not require a separate web or desktop application interface for the AutoScientist challenge deliverable.

The primary workflow is:

1. Prepare and validate the agricultural image dataset.
2. Generate the Adaptive Data training format.
3. Train the model with Adaption AutoScientist.
4. Evaluate the trained model against the provided baseline.
5. Publish the resulting project artifacts.

This directory is reserved for interface-related materials if an interface is added in the future.
